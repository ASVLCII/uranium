---
name: uranium-delivery
description: Use for a feature or fix that requires several implementation steps, scoped planning, verification and resumable progress.
---

Inspect project instructions and existing edits. Recall reviewed project knowledge. For multi-step work, create a scoped task DAG with uranium_workflow: explicit IDs, dependencies, write paths and meaningful verification commands. Validate before execution. Default to serial native tools; delegate only when the user authorizes it. Save structured progress using uranium_checkpoint after significant steps. Run the verification commands and inspect actual outcomes. Resolve failures within scope; distinguish observed checks, model claims and external CI. Finish the requested work and report remaining limitations.
